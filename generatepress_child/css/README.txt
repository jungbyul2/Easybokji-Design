==========================================

■ 어디를 고치나요?
  이 css/ 폴더의 분야별 파일을 고치면 됩니다.
  관리자 > 외모 > 테마 파일 편집기에서 파일을 열어 고치고 '파일 업데이트'를 누르면
  사이트용 파일이 자동으로 다시 만들어지고 WP Rocket 캐시도 자동으로 비워져요.
  (예전처럼 캐시를 따로 비울 필요가 없어요.)

  style.css에는 테마 정보만 있어요. style.css에 규칙을 쓰면 반영되지 않아요.

■ 지킬 것
  1. 같은 요소에 같은 우선순위의 규칙이 두 곳에 있으면 번호가 큰 파일(같은 파일이면 아래쪽)이 이깁니다.
     지금 파일 순서는 원래 화면을 그대로 지키도록 계산해서 정한 것이라 번호를 바꾸지 마세요.
  2. 새 규칙은 해당 분야 파일의 맨 끝에 추가하세요.
  3. '[순서 유지]' 주석이 붙은 규칙은 다른 분야 디자인이지만 순서 때문에 그 파일에 둔 것이에요.
     고칠 때는 그 자리에서 고치면 됩니다.
  4. !important는 꼭 필요할 때만 쓰세요. 대신 선택자를 조금 더 구체적으로 쓰면 됩니다.
     예) .eb-calc__btn 대신 .eb-calc .eb-calc__btn
  5. 새 버튼은 기본·:hover·:focus·:active 상태 색을 모두 지정하세요.
     (테마 기본 규칙 button:hover, button:focus가 배경을 파란색으로 덮어써요.)
     호버 효과는 @media (hover: hover) 안에, 키보드용 테두리는 :focus-visible로.
  6. 색은 var(--accent), var(--contrast) 같은 변수를 쓰세요(사용자 정의 > 색상에서 정한 값).
  7. 클래스 이름은 분야 접두어를 붙여요: eb-(공통), c-·hx(홈), f2·f3·ebf(맞춤 찾기), ebt·ebq(하단 탭·빠른 찾기), xh·mx(PC 헤더·메가메뉴).
     새 디자인을 만들면 그 접두어의 파일에 넣으세요.

■ 페이지 종류별로 나눠 보내기 (functions.php 64번)
  홈·글·목록·페이지마다 그 종류에서 안 쓰는 디자인을 뺀 파일을 따로 보내 화면이 빨리 떠요.
  새 글에 다른 종류의 상자(예: 홈 전용 카드)를 처음 쓰면, 그 페이지만 자동으로 전체 CSS를 받아요(안전장치).
  그런 일이 잦아지면 64번의 빼는 목록을 다시 만들면 됩니다.

■ 새 분야 파일이 필요하면
  번호를 붙여 새 .css 파일을 이 폴더에 두면 자동으로 포함돼요(번호 순서대로).
  테마 편집기에서는 새 파일을 만들 수 없어서 FTP(Cloudways)를 쓰거나 Claude에게 요청하세요.

■ 문제가 생기면
  - 바꾸기 전 내용: 관리자 > 글 > 임시글의 '[백업·공개금지] …' 글에 있어요.
  - 나눠 보내기 끄기: functions.php 64번 eb_css_split_live()의 true를 false로 → 모든 페이지가 전체 CSS(all.css).
  - 만들어진 파일 위치: wp-content/uploads/eb-css/ (all.css, home.css, post.css, list.css, page.css) - 직접 고치지 마세요.
  - functions.php 주석의 'style.css NN번'은 나누기 전 옛 번호예요. 지금은 위 분야별 파일에서 찾으세요.
