## 홈 첫 화면 시안 B (2026-10-18, 승인 대기)

방향: 더 콤팩트하게 · 찾기 쉽게 · 어르신이 읽기 쉽게. 시안 A(기존 틀 유지)를 대신합니다.

### 구조 변경

- **현재**: 탭 [조건으로 찾기 | 검색어로 찾기] 중 하나만 보임. 지도 링크는 탭 오른쪽에 떠 있어 휴대폰에서 겹침.
- **시안 B**: 탭을 없애고 세 가지를 위에서 아래로 한 번에 보여 줍니다.
  1. 검색창: 늘 보임. PC·태블릿에서는 아래에 '많이 찾는' 검색어 6개
  2. '내 조건으로 찾기' 카드
     - [나이·시기] [사는 곳] 같은 크기 선택 칸
     - [+ 가구·필요한 도움 더하기]
     - [받을 수 있는 혜택 보기] 큰 버튼
  3. 카드 맨 아래 한 줄: '지도로 우리 지역 혜택 보기 ›'

### 세부

- **문장형 선택**: "저는 ○○이고, ○○에 살아요"는 줄바꿈 위치가 화면마다 달라 칸이 들쭉날쭉했습니다. 같은 폭 칸 2개로 바꿨습니다.
- **상황별 가이드 칩**: 첫 화면에서 뺐습니다. 휴대폰에서는 옆으로 밀어야 보였고, 홈 아래 '상황별 가이드' 칸과 겹치기 때문입니다.
- **휴대폰**:
  - 날짜 줄과 설명 한 줄을 뺐습니다(카드 제목이 대신함).
  - 2주 달력 대신 '다음 지급일 + 마감 임박' 두 줄만 둡니다. 전체 달력은 '전체 일정 ›'에서 봅니다.
- **PC**:
  - 검색창이 두 칸 너비 전체를 씁니다.
  - '내 조건으로 찾기' 카드와 복지 달력의 위·아래 끝을 맞췄습니다.
  - 달력 칸을 300px에서 330px로 넓혔습니다.
- **태블릿**: 칸이 좁아 휴대폰처럼 '선택 2칸 + 더하기 한 줄'로 바꾸고, 잘리던 조합 설명 줄은 뺐습니다.
- **글씨와 누르는 곳**:
  - 첫 화면 글씨 최소 13px(배지·요일 12.5px), 흐린 회색은 #4e5968로 진하게
  - 누르는 곳 최소 44px: 선택 칸 52, 버튼 50~52, 검색어 칩 40
  - '전체 일정 ›' 같은 글자 링크도 누르는 높이 44px
- **현재 화면에서 고친 오류 2가지**:
  - 휴대폰: 지도 링크가 검색어 탭 위에 겹침
  - 768px: '결과 보기' 버튼이 카드 밖으로 12px 나감

### 확인한 것 (360·390·768·1024·1280·1440px)

- 탭·버튼 겹침 0, 카드 밖으로 나감 0, 가로 스크롤 0
- 13px보다 작은 글씨 0 (배지·요일 제외), 44px보다 낮은 누르는 곳 0 (검색어 칩 40px 제외)
- 휴대폰에서 선택 창 열기 → 고르기 → 개수 표시 동작, 스크립트 오류 0

### 시안의 한계

- 임시 WordPress에서 실제 홈 코드와 CSS로 그렸습니다.
- 글·일정은 시험용 데이터라 개수가 '0개'로 나옵니다.
- 부모 테마(GeneratePress)가 없어 맨 위 사이트 헤더는 빠져 있습니다.
- 복지지도는 공개 상태로 가정했습니다.
