# 디자인 시안

## 홈 첫 화면 시안 C (2026-10-18, 승인 대기)

방향: 콤팩트하고 정돈된 디자인 · 찾기 쉽게 · 어르신이 읽기 쉽게. 시안 A·B를 대신합니다.

| 파일 | 내용 |
|---|---|
| `home-c-phone.png` | 휴대폰 390px, 현재 / 시안 C |
| `home-c-tablet.png` | 태블릿 768px, 현재 / 시안 C |
| `home-c-pc.png` | PC 1280px, 현재 / 시안 C |
| `home-c-phone-tap.png` | 휴대폰에서 '나이·시기'를 누른 화면 / 고른 뒤 화면 |
| `home-c.css`, `home-c.js` | 시안을 그린 CSS와 구조·문구 바꾸기 스크립트. 사이트에는 쓰이지 않음 |

### 원칙

- **상자를 덜 겹치기**: 카드 안에 또 색 상자를 넣지 않고, 얇은 선(1px)으로 나눕니다.
- **둥글기와 그림자**: 둥글기는 10~12px로 줄이고(기존 14~18px), 그림자는 거의 없앴습니다.
- **조작 칸 통일**: 모든 조작 칸을 같은 높이(46px)와 같은 둥글기(10px)로 맞췄습니다.
- **간격**: 4/8/12/16px 단위만 씁니다. 카드 사이는 10px로 통일했습니다.
- **가장자리 정렬**: 검색창·카드·일정·바로가기의 좌우 끝을 모든 화면 폭에서 맞췄습니다(측정함).

### 구조

| 영역 | 시안 C |
|---|---|
| 머리 | 제목 한 줄('받을 수 있는 지원금, 30초면 알아요'), 신뢰 표시는 글자만 |
| 검색창 | 늘 보임. 태블릿·PC는 아래에 '많이 찾는' 검색어를 글자 링크로 |
| 내 조건으로 찾기 카드 | 1줄: 제목 ··· 지도로 찾기 › / 2줄: 안내(고른 뒤에는 '받을 수 있는 혜택 N개') / 조작 칸 [나이·시기] [사는 곳] [+ 조건 더하기] [혜택 보기] (휴대폰·태블릿 2×2, PC 한 줄) / PC·태블릿: '많이 찾는 조합' 칩 한 줄 |
| 다가오는 일정 | 색 상자 대신 목록 두 줄: [D-2] 지급일, [D-43] 마감. PC는 2주 줄 달력 추가 |
| 바로가기 8칸 | 칸마다 카드 대신 흰 판 하나. 휴대폰 4×2(이름만), PC 8칸 한 줄(얇은 세로선) |

- **화면 폭별**: 휴대폰·태블릿은 한 줄로 쌓고, PC(1080px~)만 '찾기 | 일정' 두 칸입니다.
- **첫 화면에서 뺀 것**: 상황별 가이드 칩(홈 아래 칸과 겹침), 휴대폰의 날짜 줄과 2주 달력

### 측정 (360·390·768·1024·1280·1440px)

- 바로가기 시작 위치(휴대폰 390px): 현재 814px → 시안 C 508px
- 겹침·카드 밖으로 나감·가로 스크롤 0
- 13px보다 작은 글씨 0 (배지·요일 12.5px 제외), 44px보다 낮은 누르는 곳 0 (검색어·조합 칩 40px 제외)
- 휴대폰에서 선택 창 열기 → 고르기 → 개수 표시 동작, 스크립트 오류 0

### 적용하면 고칠 파일 (승인 후)

| 파일 | 고칠 내용 |
|---|---|
| `css/50-home.css` 끝 | 시안 CSS 정리본 |
| `functions.php` 48번 `eb_hero_v3_html` | 카드 머리, 조작 칸(`.hx__ctl`) HTML, 탭 줄 제거, 제목·버튼·일정 제목 문구, 화면 스크립트의 '가구·필요한 도움 더하기' 문구 |
| 복지지도 `inc/page.php` | `ebm_home_link()` 위치·문구('지도로 찾기')와 위치 고정 스타일 제거 |

### 시안의 한계

- 임시 WordPress에서 실제 홈 코드와 CSS에 시안 CSS·스크립트를 얹어 그렸습니다.
- 시험용 데이터라 개수가 '0개'로 나옵니다.
- 부모 테마(GeneratePress)가 없어 맨 위 사이트 헤더는 빠져 있습니다.
- 복지지도는 공개 상태로 가정했습니다.
