# 디자인 시안

## 홈 첫 화면 시안 A (2026-10-18, 승인 대기)

방향: 더 콤팩트하게 · 찾기 쉽게 · 어르신이 읽기 쉽게

- 비교 이미지: `home-a-phone.png`(390px), `home-a-tablet.png`(768px), `home-a-pc.png`(1280px)
- 시안 CSS: `home-a.css`
  - 시안 확인용으로만 씁니다. 사이트에는 쓰이지 않습니다(`css/` 폴더 밖).
  - 승인되면 `css/50-home.css` 끝에 정리해 넣습니다.
  - 휴대폰 일정 제목 문구는 `functions.php`에서 바꿉니다.
- 만든 방법: 임시 WordPress에서 실제 홈 코드와 CSS로 화면을 그리고 시안 CSS를 얹어 촬영했습니다.
  - 글·일정은 시험용 데이터이고, 복지지도는 공개 상태로 가정했습니다.
  - GeneratePress 부모 테마 없이 찍어서 헤더 모양은 실제와 다릅니다.

### 바뀌는 점

| 문제 (현재) | 시안 A |
|---|---|
| 휴대폰: '지도로 찾기'가 '검색어로 찾기' 탭에 겹침 | 휴대폰에서 탭 3개(조건·검색어·지도)를 같은 폭으로 한 줄에 |
| 태블릿 768px: '결과 보기' 버튼이 카드 밖으로 12px 나감 | 안내 글과 버튼을 한 줄로 맞춰 카드 안에 |
| 첫 화면 작은 글씨 10.5~12.5px | 최소 13px (배지·요일 글자만 12.5px), 옅은 회색은 한 단계 진하게 |
| 휴대폰 첫 화면에 바로가기 8칸이 안 보임 | 날짜 줄·2주 달력을 빼고 신뢰 표시는 한 줄로 → 바로가기가 106px 위로 올라와 첫 화면 끝에 보이기 시작 |
| 고르는 칸 38px | 44px 이상(누르기 쉬운 크기) |

PC는 글씨 크기와 결과 줄만 바뀌고 배치는 그대로입니다.
