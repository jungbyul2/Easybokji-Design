# 복지지도 공개 전 점검 (2026-10-18)

## ① 홈 '지도로 찾기' 겹침 수정 — `plugins/eb-welfare-map/inc/page.php`

- **문제**: 복지지도를 공개하면 휴대폰(767px 이하)에서 '지도로 찾기' 링크가 '검색어로 찾기' 탭 글자 위에 겹침
- **수정**: 휴대폰에서만 탭 줄을 같은 폭 3칸으로 나눔(조건으로 찾기 | 검색어로 찾기 | 지도로 찾기, 아이콘 없이 14px). 지도 링크는 셋째 칸에 꼭 맞게 둠. 태블릿·PC는 그대로
- **확인**: 320·360·390·414·600·767·768·1024·1280px에서 겹침 0, 글자 잘림 0, 칸 밖으로 나감 0

## ② 복지지도 화면 점검 — `plugins/eb-welfare-map/assets/map.css` 끝 '화면 점검 손질'

### 점검 방법

- 임시 WordPress에 자식 테마와 복지지도 플러그인을 설치하고 **시험용 가짜 데이터**(지역 128건·전국 40건)를 넣음
- GeneratePress 본문 틀은 비슷하게 만들어 씀(여백 PC 40px·휴대폰 20px). 실제 사이트 여백과 조금 다를 수 있음
- 360·390·768·1024·1280px에서 자동 측정. 휴대폰은 터치, PC는 키보드로 동작 시험

### 동작 시험 (11개 모두 통과)

| 시험 | 결과 |
|---|---|
| 지역 검색 '수원' → 추천 → 누르기 | 주소 `?sd=경기도&sg=수원시`, 수원시 사업 표시 |
| 뒤로 가기 | 이전 화면(전국)으로 |
| 대상 '노년' 누르기 | 선택됨, 주소에 `life=노년`, 화면 튐 0px |
| 지도 펼치기 | 지도 보임 |
| 다른 시·군·구 | 시·군·구 목록 열림 |
| 내 조건으로 더 좁히기 | `/find/?sd=경기도&sg=가평군`, 맞춤 찾기에 '경기도 가평군' 선택됨 |
| PC 키보드 Tab → 지도 지역 → Enter | 지역 테두리 파란색 + 이름 말풍선, Enter로 그 지역 열림 |
| 스크립트 오류 | 휴대폰·PC 0건 |

### 고친 것 (손질 전 → 후)

| 항목 | 손질 전 | 손질 후 |
|---|---|---|
| 작은 글씨 | 12.2~12.8px 11곳(상태 배지, 적용 지역, 수정일, 안내, 건수, 자료 출처 등) | 모두 13px 이상(rem이라 사이트 글자 크기 버튼을 따라감) |
| 누르는 높이 | 경로 링크 19px, 버튼 32px, 칩 34px, 일정·기관 글자 링크 22px, 이름 검색칸 38px | 경로 44px, 나머지 40px 이상 |
| 휴대폰 경로 줄 | '선택 지우기'만 혼자 둘째 줄 | 1줄 '전국 › 경기도 › 가평군' / 2줄 [다른 시·군·구] ··· 선택 지우기(글자 링크). 긴 이름(전남광주통합특별시)도 안 잘림 |
| PC 대상 칩 | 생애주기·가구 구분선이 둘째 줄 맨 앞에 붙음 | 가구 상황 칩은 새 줄에서 시작 |

손질 후 다시 측정: 5개 화면 폭 모두 좌우 밀림 0, 13px 미만 글씨 0, 40px 미만 누르는 곳 0(지도 위 시·군·구 모양은 같은 목록이 따로 있어 제외).

### 고치지 않고 제안만 하는 것

- **같은 안내가 두 번 나옴**: '지역을 골랐다고 대상이 되는 건 아니에요'가 페이지 머리 설명과 '고른 지역' 카드에 둘 다 있음. 머리 쪽을 빼면 휴대폰 첫 화면이 2줄 줄어듦(문구 변경이라 승인 후)
- **휴대폰 필터 칩**: 옆으로 밀어야 보이는 칩이 화면 끝에서 잘려 보임('청소년', '기간 확인 필요'). 어르신이 옆으로 밀 수 있다는 걸 모를 수 있음 → 줄바꿈 + '더 보기'로 바꿀지 검토
- **카드 길이**: 휴대폰 카드 하나가 약 215px이고, 시·군·구 10개 + 시·도 10개가 이어짐. 지금도 '더 보기'로 나눠 보여 주지만 더 콤팩트하게 할 여지 있음
