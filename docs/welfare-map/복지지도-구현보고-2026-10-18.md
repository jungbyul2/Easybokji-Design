## 2. 만든 것

### 2-1. 화면 `/welfare-map/` (플러그인 `eb-welfare-map`)
- 지역 고르기 3가지가 같은 지역 ID로 동작: **지역명 검색**(콤보박스, `경기 수원`·`광산`·옛 이름 `광주 광산` → 전남광주 광산구) · **전국/시·도 지도**(SVG, 클릭·탭·Tab+Enter) · **텍스트 목록**(지도와 같은 선택 수단, 건수 표시).
- 결과 묶음: **시·군·구 사업 / 시·도 전체 사업 / 전국 공통 사업** + 접힌 **'적용 지역 확인 중인 ○○ 사업'**. 세종은 단층이라 시·도 하나.
- 카드: 상태 · 적용 지역 · 이름·기관 · 대상(생애주기·가구) · 혜택(지원주기·제공유형, 없으면 사업 목적) · 기간·D-day · 복지로 수정일 / 이지복지 확인일 · **공식 정보 보기**(복지로) · 연결된 정리 글·캘린더 일정.
- 신청 상태는 근거가 있을 때만: 관리자가 공고로 확인한 기간·상시·마감, 또는 캘린더의 **확인된(노출 중) 일정** 연결. 나머지는 모두 **'기간 확인 필요'**. 날짜로 접수 중/곧 시작/마감을 방문자 기기 날짜로 계산(캐시 대비).
- 필터: 대상(생애주기 7 + 가구 상황 6) · 지원 분야 · 신청 상태 · 사업 이름. 칩마다 건수, 바꿔도 화면이 위로 튀지 않음.
- 주소에 지역·필터가 남아 **새로고침·공유해도 같은 결과**(`?sd=경기도&sg=가평군&st=open`). 옛 이름 주소는 지금 이름으로 이어 줌, 둘로 나뉜 곳(인천 옛 중구)은 고르게 함. 뒤로 가기 지원.
- 첫 목록은 서버에서 그림(스크립트·지도가 실패해도 목록·검색으로 이용). 지도 실패·API 실패·빈 결과 각각 안내와 '다시 시도'.
- "지역을 골랐다고 대상이 되는 건 아니에요" 문구, '받을 수 있음' 표현 없음. 자료 출처·받은 날, 지도 출처(SGIS·CC BY 4.0), 개인정보(주소·위치 권한 안 씀, 지역은 이 기기에 기억) 안내.
- 휴대폰: 검색 → (시·도 목록 →) 고른 지역 → 필터 → 목록 → 접힌 작은 지도. 시·군·구를 고른 뒤엔 '다른 시·군·구' 버튼으로 목록을 엶. 태블릿: 목록 | 지도 나란히 + 결과 전체 폭.

### 2-2. 다른 기능과의 연결
| 연결 | 동작 |
|---|---|
| 맞춤 찾기 → | '내 조건으로 더 좁히기': 맞춤 찾기 기록(eb_finder_last)의 시기·가구·도움은 **읽기만** 해서 그대로 + 지도 지역만 넣어 `/find/?…&sd=&sg=` 로 엶 |
| ← 맞춤 찾기 | '사는 곳' 아래 "○○ 정책 전체 보기 · 복지지도 ›" (고른 지역을 따라감) |
| 지역 하나로 | 지도는 캘린더와 같은 `ebs_region`만 씀. 맞춤 찾기·홈 찾기·빠른 찾기가 **더 나중에 고른 지역**을 쓰도록(개인 조건은 유지) — 시험: 지도에서 강남구 → /find/ 를 조건 없이 열면 '청소년 + 강남구' |
| 복지 캘린더 | '이 지역 일정' → `/schedule/?sd=&sg=#applying` (주소의 지역으로 열리게 함). 지도 요약은 확인된 시·군·구 일정 + 관리자가 연결한 일정만, 기간은 캘린더와 같은 값. 알림은 캘린더 종 버튼으로(지도에 알림 없음) |
| 우리 동네 기관 | '신청할 곳 찾기' + "정확한 관할은 주소를 넣어 확인" (지역만으로 기관을 정하지 않음) |
| 상황별 가이드 | 이 지역 사업 중 각 상황 조건(맞춤 찾기 상황 타일과 같은 조건)에 맞는 수로 상위 4개 |
| 편집 글 | 이 시·도 대상 글(옛 시·도 태그도 이어 줌) 먼저 + 고른 조건과 겹치는 글, ☆로 저장 |
| 저장한 글 | '이 지역 저장' ☆ → 저장한 글에 "경기도 수원시 복지지도"로 들어감(기존 eb_saved 형식) |
| 홈 | 찾기 카드 탭 줄 오른쪽 **'지도로 찾기'** (기존 찾기 화면은 그대로) |
| 메뉴 | PC 메가메뉴 '바로 쓰는 도구' 둘째 칸, 휴대폰 전체 메뉴 '바로 쓰는 도구' 맨 위 |
| 검색 | 공개하면 사이트 검색 추천에 페이지가 자동으로 들어감(기존 search-index 규칙) |

### 2-3. 관리자 '복지지도' 메뉴
- **상태**: 공개 전환(전에는 페이지 비공개·메뉴/홈/API/검색 숨김) · 원본 받은 시각·36시간 멈춤 경고·오류 · 원문 수정일 저장 여부 · 적용 범위 통계 · 캐시 다시 계산.
- **검수**: 적용 지역 확인 필요 / 옛 지역 이름 / 중복 후보 / 원문 오래됨(1년 반+) / ID·주소 없음 / 검수한 것 / 확인 기간 지남 / 사라진 사업. 줄마다 빠른 버튼('부산 전체로 확인', '추천: 가평군만') + 자세히: 적용 범위·시·군·구 체크, 신청 상태(모름/상시/기간/마감)+근거 링크, 캘린더 일정 연결(이름 추천은 '추천'으로만), 대상·혜택 한 줄, 정리 글 번호, 메모. 마감일 없는 '기간 있음'은 저장 안 함(접수 중 오표시 방지).
- **지역 코드표**: 시·도 16·시·군·구 229 코드, 옛 이름, 맞춤 찾기·캘린더 지역 이름 대조(지금은 인천 중구·동구만 '옛 이름').

## 6. 남은 데이터 제약·할 일
1. **신청기간은 원본에 없음** → 처음엔 거의 모든 지역 사업이 '기간 확인 필요'. 관리자 검수(공고 확인)나 캘린더 일정 연결로만 늘어남. 많이 찾는 지역부터 검수 권장.
2. **적용 지역 확인 필요 79건**(시·군·구 빈칸 66, 통합 전 기준 13) — 공개 전에 검수하면 좋음. 관리자 추천(기관 이름)은 부산형 산후조리비처럼 틀릴 수 있어 원문 대조 필요.
3. 원문 수정일·지원주기·제공유형은 **테마 패치 후 다음 받기부터** 저장(배포 직후 '지금 지역 서비스 받기' 권장, API 약 10회).
4. 정부 서비스 목록 API의 수정일 필드 이름은 미확인 — 패치가 첫 항목 원본을 저장하니 배포 후 '복지지도 > 상태'에서 확인.
5. 옛 인천 중구·동구 7건은 복지로 원문이 고쳐질 때까지 새 구들에 '옛 지역' 안내로 표시.
6. 캘린더의 시·도 단위 지역 일정은 지도 요약에 넣지 않음(시·도 기관이 한 시·군·구 사업을 하는 경우가 있어서) — 필요하면 검수에서 정책에 연결.
7. 확인 필요: 운영 '받은 시각'이 2026.10.17 04:30 — 10.18 04:30 받기가 됐는지 설정 > 복지서비스 API에서 확인 필요(36시간 넘으면 복지지도가 '갱신 늦음'을 표시).
8. 하지 않은 것: 지역 비교·새 정책 알림(지시대로 제외), 상세 API로 대상·혜택 자동 채우기(상세 API 응답 미확인 — 다음 단계), 전체 검색에 지역 정책 유형.
9. PC 메가메뉴 도구가 10칸이 되어 '저장한 글'이 넷째 줄 — 오른쪽 가이드 상자와 높이는 맞음. 원하면 배치 조정.
