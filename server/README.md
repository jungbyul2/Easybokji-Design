# server/ — 운영·스테이징 공통으로 둘 수 있는 서버 파일

| 파일 | 둘 곳 | 설명 |
|---|---|---|
| `mu-plugins/eb-tocer-local-settings.php` | `wp-content/mu-plugins/` | tocer(목차)가 자기 기본 설정 파일을 HTTP로 자기 사이트에 요청하는 대신 디스크 파일을 바로 읽게 함. 스테이징 비밀번호 보호 때문에 생기던 500 오류의 해결책이자, 운영에서 요청 실패 시 사이트가 멈출 위험을 없앰. 원인·시험: `docs/deploy/복지지도-운영반영-계획.md` 9절 |

`staging/` 폴더의 파일과 달리 운영에 올려도 되는 파일입니다. 단, 운영 반영은 승인 후에 합니다.
